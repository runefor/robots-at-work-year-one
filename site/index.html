  • 기존 VR 텔레옵(Open-TeleVision류)은 허리가 없고 핸드 트래킹 실패 시 충돌 위험. 엑소스켈레톤+VR 하이브리드에 HMD 포즈로 허리를 추정하도록 만들어 작업 영역이 2배 이상 늘고, 60 에피소드 수집이 하루에서 몇 시간으로.
  • 모델은 ACT가 가장 잘 됐고 빠름. 20개 안 되는 에피소드 + 도메인 랜덤화로 동작. 관람객이 배경에 서면 정책이 깨져서 랜덤화를 강화.
  • 액션 청크 경계의 불연속이 하드웨어를 망가뜨린다. temporal ensemble은 멀티모달 액션(왼쪽/오른쪽 평균 → 가운데)에서 실패하므로, 청크 블렌딩 + 저크 최소화 후처리 프레임워크를 개발.

로보티즈 표윤석 부사장님

27년간 다이나믹셀을 만들어 온 하드웨어 회사가 왜, 어떻게 피지컬 AI로 방향을 틀었는가.

  • 전환의 계기는 Mobile ALOHA. “연구자를 갈아 넣어야” 나오던 모션이 데이터 학습만으로 동작하는 걸 보고, AI 연구팀(Apple·Disney·DeepMind·Hugging Face LeRobot)이 자사 액추에이터를 쓰는 걸 발견.
  • 두 갈래 제품: 모바일 베이스 양팔형 AI Worker(모방학습 특화)와 이족보행 AINEX(강화학습 특화, 130cm·35kg·23 DoF).
  • 물류센터는 이미 60~70% 자동화, AMR이 다니는 평탄한 공간. 거기서 장애물 돌파형 이족보행은 필요 없다 → 모바일 베이스 + 큰 배터리 + 스워브 드라이브.
  • VR 텔레옵은 전시용으로 최고지만 8시간 일 못 한다. 실제 데이터 수집은 리더암 타입, 난제는 그리퍼 가림과 카메라 FOV.
  • 룰베이스 시절(DARwIn-OP, DARPA THORMANG)엔 넘어지고 망가지는 게 일상. 지금은 AINEX가 출시 1주일 만에 걷고, 학생팀이 2주 만에 백덤블링급 동작을 구현.
  • 워크플로: 비디오에서 사람 모션 추출 → 리타게팅 → Isaac Lab 병렬 학습 → 실로봇. 데이터·코드·모델·문서 전부 오픈소스.
“그런 공간에서 굳이 장애물을 돌파해야 되는 이족보행 휴머노이드 로봇은 솔직히 필요 없습니다.”

AI Robotics KR 운영진 / Meta Farmers 라이트닝톡

  • 딸기 농장은 비정형 환경이며, 범용성보다 안정적인 반복 운영이 중요하다.
  • 수확 품질은 Coverage, Success Rate, Damage Rate로 본다. 빠르게 따는 것보다 놓치지 않고·손상 없이 따는지를 함께 봐야 한다.
  • 정상 수확 수익 약 50원 vs 손상 과실 손실 약 500원 — 실패 비용이 성공 이익보다 훨씬 크다.
  • 하나의 범용 그리퍼보다 작물·작업에 맞춰 end-effector를 교체하는 모듈형 접근과, 변화하는 농장 데이터를 반복 수집하는 운영 방식.
산업 로보틱스 · 조선소 · RL + 고전 플래닝

디든로보틱스 김준하 대표님

“Physical AI for Industrial Sites” — 조선소·플랜트·건설처럼 코봇도 갠트리도 못 쓰는 비정형 현장을 위한 자석발 스파이더 로봇과 고가반 휴머노이드.

  • 로봇을 쓰는 이유는 둘뿐: 사람이 들어가면 안 되는 곳, 또는 사람보다 확실히 잘해야 하는 곳.
  • 범용 휴머노이드는 가성비가 안 나온다: 덱스터러스 핸드 한쪽 7천만 원, 전신 3억. 현장 대부분은 2지/3지 그리퍼로 충분 → 가반하중 30kg(작업자 한계 15kg의 2배) 그리퍼 휴머노이드.
  • 중국산 구동기는 150N·m 표기에 실측 100N·m, 10회 실험이면 베어링 파손. 모터 보드·하우징·기어박스를 직접 설계.
  • 자체 자석발: 착탈 16ms(상용품 1초), 1.8kg로 흡착력 200kg. 학습 때 자석이 10% 확률로 실패하게 만들면 로봇이 스스로 옆을 더듬어 복구하는 행동을 배운다.
  • 40cm 장애물·개구부·바닥→벽면 전환은 RL로 30cm도 안 풀렸다. 다리 하나씩 RRT를 푸는 방식으로 돌아갔으나 800초 → 다리별 궤적을 라이브러리화해 실시간 근처로.
  • 휴머노이드 모션은 비디오 모션캡처 → 리타게팅 → DeepMimic/AMP. 90kg 로봇이 농구·태권도·박스 리프팅. 조선사 납품 개시, 운영 목표는 1명이 8대 관제.
“저는 로봇을 쓰는 이유가 두 가지라고 생각하거든요. 진짜 사람이 들어가면 안 되는 데를 들어가거나, 아니면 사람보다 일을 진짜 잘해야 한다.”
“범용 로봇으로 가면 갈수록 오히려 상용화하기가 어렵다. 최적화된 로봇을 만들어서 기술을 빨리 낸다고 생각하는 사람이에요.”
자율이동 · SLAM · 비정형 환경

유로보틱스 유병호 대표님

“비정형 산업 환경에서 로봇은 어떻게 이동의 자율을 얻는가” — 하드웨어 없이 이동 소프트웨어만 파는 15명 KAIST 출신 스타트업.

  • 정형 환경의 이동은 이미 풀렸다. 남은 건 지도가 어제와 오늘 다른 공장, GPS 음영의 선박 하부, 피처가 없고 반복적인 지하주차장·건설현장 — 기존 SOTA SLAM이 실패하는 곳.
  • 파라미터 튜닝이 아닌 “언제 어디서나 동작하는” SLAM. 통유리 엘리베이터, 라이다에 모자를 씌운 상황에서도 IMU·엔코더만으로 발산하지 않고, 엣지에서 약 50Hz.
  • 포인트클라우드 지도는 유지보수가 비싸다. 실내는 CAD 도면에 소화기·충전 스테이션 기준으로 정합, 실외는 스마트폰 사진 기반 로컬라이제이션.
  • 세그멘테이션→트래킹→경로예측 같은 팬시한 파이프라인보다, 트래버서빌리티를 동적으로 재계산해 엣지에서 실시간으로 도는 게 중요.
  • 블라인드 보행: CPU 소형 네트워크로 1~2ms 응답(사람 자세 반사 ≈ 80ms). 관절 고장을 스스로 추정해 보행 패턴을 다시 만든다. 2023 QRC 우승(246점 vs 2위 60점).
  • 로드맵: 무거운 VLA/LLM은 필요할 때만 호출. “길 건너 스타벅스 가서 커피 사와”를 LLM으로 분해하고 3D 맵에서 문·엘리베이터 POI를 뽑는 KAIST 공동연구.
“산업 현장에서는 이미 로봇들이 잘 움직이고 있었어요. 휴머노이드는 아닐 뿐이었죠.”
“사람들은 발을 많이 보면서 걷지 않거든요. 근데 대다수의 로봇 회사들이 발을 보면서 걸어요.”

Reinforcement Learning

PPO와 SAC: 무엇을 먼저 비교해야 하나

입문. 강화학습은 행동 뒤의 보상을 보고 다음 행동을 더 잘 고르는 방법이다. PPO는 새 정책이 한 번에 너무 크게 바뀌지 않게 제한하는 on-policy 계열이고, SAC는 과거 경험을 재사용하는 off-policy 계열이며 행동의 다양성도 장려한다.

실무/실험 관점알고리즘을 고르기 전에 관측(state), 행동(action), 성공 판정, 안전 한계가 먼저다. PPO는 구현과 튜닝의 기준점으로, SAC는 연속 제어에서 샘플 재사용이 중요할 때 비교 대상으로 두기 좋다. 상태·보상 정규화는 각 입력과 학습 신호의 스케일을 안정화하는 기본 점검 항목이다.

발표 맥락. 박종혁 교수님 메모에서 PPO·SAC와 정규화는 “상태와 보상 설계” 다음에 적용할 도구로 언급됐다.

Reward Design

보상 설계와 reward hacking

입문. 에이전트는 사람이 바란 결과가 아니라 보상식이 주는 점수를 최대로 만든다. 따라서 점수는 높지만 실제 작업은 실패하는 “명세의 빈틈”이 생길 수 있다.

실무/실험 관점성공률 하나로 끝내지 말고, 충돌·에너지·시간·자세·안전 제약을 별도 지표로 로그에 남긴다. 보상 변경 전후에는 정책 영상을 사람이 검토하고, 악용 가능한 지름길을 찾는 테스트 시나리오를 둔다. LLM은 보상 후보 코드 생성과 실험 요약을 도울 수 있지만, 보상 검증 책임을 대신하지는 않는다.

발표 맥락. 현장 메모에는 보상 해킹의 위험과 LLM을 이용한 보상 설계 실험이 언급됐다.

  • DeepMind의 specification gaming 사례
  • RL-VLM-F: 모델 피드백을 보상으로 쓰는 연구
Sim-to-Real

시뮬레이션에서 되던 일이 왜 현실에서 안 될까

입문. 시뮬레이터는 현실의 복사본이 아니라 빠른 근사 모델이다. 마찰, 백래시, 센서 노이즈, 지연, 조명, 물체 상태가 조금만 달라도 정책은 전혀 다른 입력을 받을 수 있다.

실무/실험 관점현장 계측으로 질량·마찰·지연의 범위를 먼저 잡고, 학습 때 그 범위를 흔드는 domain randomization을 적용한다. 전이 평가는 시뮬레이터 점수가 아니라 실제 성공률, 실패 모드, 복구 가능성으로 한다.

발표 맥락. 박종혁 교수님 메모는 특히 접촉과 마찰/미끄러짐을 현실 격차의 어려운 예로 들었다.

  • Dynamics randomization을 이용한 Sim-to-Real
  • 랜덤화 시뮬레이션 로봇 학습 리뷰
Learning from Data

모방학습, GAIL, 오프라인 강화학습

입문. 모방학습은 전문가 시연을 보고 행동을 배우고, GAIL은 “전문가처럼 보이는가”를 판별하는 신호를 이용해 이를 확장한다. 오프라인 강화학습은 새로 환경을 탐험하지 않고, 이미 모은 로그 데이터만으로 정책을 학습한다.

실무/실험 관점셋 모두 데이터 범위 밖의 행동에 약해질 수 있다. 데이터가 성공·실패·예외 상황을 얼마나 포함하는지, 센서와 행동의 시간 동기화가 맞는지, 실제 배포 전 안전 제약이 있는지를 먼저 점검한다. 최대 엔트로피 학습은 보상뿐 아니라 행동의 불확실성과 탐색 다양성도 함께 고려하는 관점이며 SAC의 기반 중 하나다.

발표 맥락. 박수한 교수님은 20개 미만 에피소드로 ACT를 학습시키되 청크 경계 블렌딩과 저크 최소화를 후처리로 붙였고, 표윤석 부사장님은 “VR은 8시간 일 못 한다”며 리더암 기반 수집의 가림·FOV 문제를 짚었다. 데이터 수집 장치의 설계가 곧 학습 품질이라는 점이 두 발표의 공통점.

  • GAIL 원 논문
  • Offline RL 튜토리얼·리뷰
Planning & Control

RRT + MPC: 길 찾기와 따라가기의 분업

입문. RRT는 충돌 없는 경로 후보를 넓게 탐색하는 데 쓰이고, MPC는 현재 상태를 계속 반영해 짧은 미래를 예측하며 제어 입력을 갱신한다. 한쪽은 “어디로 갈지”, 다른 쪽은 “지금 어떻게 움직일지”에 가깝다.

실무/실험 관점RRT 경로가 실제 구동기의 속도·가속도·접지 한계를 만족하는지, MPC의 모델 오차와 계산 시간이 제어 주기에 들어오는지 측정한다. 학습 기반 정책과 결합할 때도 충돌 회피와 안전 제약의 최종 책임을 어디에 둘지 분명히 해야 한다.

발표 맥락. 김준하 대표님: 자석발 보행은 RL로 풀렸지만 40cm 장애물·벽면 전환은 RL로 30cm도 안 됐다. 다리 하나씩 RRT로 돌아갔더니 800초가 걸려, 궤적 라이브러리로 실시간 근처까지 당겼다. “안 풀리면 과거로 돌아간다”는 실패→우회 서사.

  • RRT 원 논문
  • MPC를 포함한 궤적 최적화·제어 강의 노트
Deployment

산업 현장에서는 왜 하드웨어와 경제성이 중요한가

입문. 로봇은 모델만으로 존재하지 않는다. 센서, 구동기, 기구, 작업물, 작업자, 정비 흐름이 한 시스템이다. 범용 능력보다 특정 공정에서 매일 같은 품질로 일하는 능력이 더 큰 가치가 될 수 있다.

실무/실험 관점PoC의 성공 기준에 처리량·가동률·복구 시간·유지보수 시간·작업자 개입·원가를 함께 둔다. 데이터 수집도 일회성 프로젝트가 아니라 현장 변화에 맞춰 반복되는 운영 체계로 설계한다.

발표 맥락. 네 발표가 같은 결론으로 수렴했다. 박수한(저크 최소화 = 내구성 = ROI), 표윤석(평탄한 물류센터엔 이족보행 불필요), 김준하(덱스터러스 핸드 3억은 가성비가 안 나온다 → 30kg 그리퍼), 유병호(팬시한 파이프라인보다 엣지 실시간).
